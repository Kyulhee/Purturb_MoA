# 실험 보고서 01: GNN 임베딩 중복성 — XGBoost 단독이 더 낫다

**실행:** run_01 | **날짜:** 2026-04-26 ~ 27 | **결과:** 실패

---

## 가설

대사 네트워크의 GNN(HGT) 임베딩이 knockout mask 외에 추가 예측력을 제공한다. GNN+XGBoost 하이브리드가 XGBoost 단독을 능가할 것이다.

## 실험 설계

- **데이터:** E. coli iML1515 서브셋 (유전자 137, 대사물 72, 반응 95), FBA 샘플 837개
- **비교 모델:** XGBoost 단독 vs GNN+XGBoost (frozen/비사전학습/edge 사전학습)
- **GNN:** HGT, 32d 또는 153d 임베딩

## 결과

| 모델 | R2 |
|------|-----|
| **XGBoost 단독** | **0.911** |
| GNN+XGBoost (frozen, 32d) | 0.824 |
| GNN+XGBoost (비사전학습, 153d) | 0.960 |
| GNN+XGBoost (edge 사전학습, 153d) | 0.906 |

frozen 임베딩은 오히려 성능 하락. 153d 비사전학습만 근소 우위이나, 이는 차원 증가에 의한 과적합으로 판단.

## 실패 원인

**Knockout mask가 이미 충분 통계량이다.** FBA는 어떤 유전자가 knockout 되었는지의 결정론적 함수이며, 그래프 구조는 모든 샘플에 동일하다. 따라서:

1. 정적 그래프는 샘플 간 판별력이 없음
2. GNN 메시지 패싱은 노이즈로 작용
3. Edge 예측 사전학습은 성장률 예측과 무관

## 얻은 지식

- GNN은 그래프가 샘플마다 다르거나, edge weight가 물리량을 인코딩하거나, 노드 feature가 불완전할 때만 의미 있음
- 사전학습 과제는 다운스트림 과제와 정렬되어야 함
- 테이블 형태 + 완전 feature에서는 XGBoost가 강력한 베이스라인
- "GNN 대리모델"은 이미 기존 연구에서 구현되어 신규성 없음
