# 실험 보고서 02: 액티브 러닝 실패 — 랜덤 샘플링보다 열위

**실행:** run_01, run_03 | **날짜:** 2026-04-26 ~ 27 | **결과:** 실패

---

## 가설

다양성(Hamming distance) + 불확실성(ensemble UCB) 기반 액티브 러닝이 XGBoost 대리모델 학습에서 랜덤 샘플링보다 효율적이다.

## 실험 설계

- **run_01:** GNN 임베딩 공간에서 diversity + UCB (200 초기 + 5라운드×20)
- **run_03:** 입력 공간에서 Hamming distance + ensemble UCB (동일 예산)
- **비교:** 동일 예산의 랜덤 샘플링

## 결과

| 전략 | FBA 호출 | 최종 R2 |
|------|----------|---------|
| **랜덤** | 100 | **0.676** |
| AL (diversity + UCB) | 100 | 0.560 |

**AL이 17% 더 나쁨.** UCB 단계로 전이조차 실패 — R2가 0.3 임계값을 지속적으로 넘지 못함.

## 실패 원인

1. **다양성 ≠ 정보성:** 입력 공간에서 다르다고 예측에 유익한 것은 아님. 유전자가 많이 달라도 성장률이 비슷할 수 있음(기능적 중복성)
2. **UCB의 계란-닭 문제:** 불확실성 추정이 정확하려면 대리모델이 이미 좋아야 함. 그런데 모델이 좋아지려면 좋은 샘플이 필요함
3. **FBA가 너무 빠름:** 1회 ~30ms. 평가가 싸고 입력 공간이 작아(137차원 이진) AL의 이점이 원래 미미
4. **XGBoost의 강건성:** 내장 정규화 덕분에 훈련 데이터 구성에 덜 민감

## 얻은 지식

- AL 획득 함수는 작업과 정렬되어야 함. 입력 공간 다양성만으로는 불충분
- 평가가 싸고 입력 공간이 잘 커버되면 AL의 한계 이점이 거의 없음
- 진짜 병목은 샘플 효율성이 아니라 모델 선택과 다목적 최적화
