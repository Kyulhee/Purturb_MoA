## 1. 구조적 문제: 문헌 리뷰의 체계적 맹점

### 1.1 교차 도메인 검색 누락 (가장 치명적)

**무슨 일이 있었나:** "예측 잔차→에피스태시스 분해의 직접 경쟁자 0개"라는 주장은 **섭동 생물학 도메인 내에서만** 성립했다. 그러나:

| 누락된 선행 | 분야 | 핵심 아이디어 | 발견 시기 |
|------------|------|-------------|----------|
| Tan et al. (2018, JMLR) | XAI 이론 | 가법 근사의 잔차 = 비가법적 구조 | run_09 이후 2차 novelty 스캔 |
| Diamond (Chen et al. 2024) | ML 해석가능성 | ML 모델에서 비가법적 feature interaction 탐지 + FDR 제어 | run_09 이후 2차 novelty 스캔 |
| MoCHI (Faure & Lehner 2024, Genome Biology) | 단백질 DMS | NN 잔차에서 energetic coupling/epistasis 추정 | run_09 이후 2차 novelty 스캔 |
| Otwinowski et al. (2018, PNAS) | 단백질 DMS | I-spline 비선형 매핑 → 잠재 형질 가법 모델 → HOC 잔차 = 에피스태시스 | run_09 이후 2차 novelty 스캔 |
| Birgy et al. (2026, Nature Comms) | 단백질 안정성 | 안정성 모델 편차 = 구조적 에피스태시스 | run_09 이후 2차 novelty 스캔 |

**왜 누락되었나:**
- 문헌 리뷰가 "perturbation prediction" + "epistasis" + "gene interaction" 용어 체계에 국한
- "residual analysis" + "non-additive" + "model error decomposition" 등 교차 도메인 용어를 검색하지 않음
- 생물학 → ML/XAI, 단백질 → 유전자 섭동의 도메인 장벽을 넘지 못함

**교훈:** "경쟁자 0개" 주장은 검색 공간이 좁을수록 쉽게 성립. 도메인 전문 용어를 번역하여 타 도메인에서 검색하는 절차가 필수.

### 1.2 직접 경쟁자 누락 (1차 리뷰에서)

초기 문헌 리뷰(run_01-06)에서도 섭동 생물학 내 경쟁자를 놓침:

| 누락 | 발견 시기 | 영향 |
|------|----------|------|
| BuDDI (Davidson 2025) | run_08 루프백 | VAE 4-분해 + 도메인 불변성 → FCR-ICM과 원리 유사 |
| C3TL (arXiv:2603.13051) | run_08 루프백 | 인과 불변성 원리로 교세포 전이 → ICM 핵심 아이디어의 선행 |
| scDRP (Sun 2025) | run_08 루프백 | β-VAE + 인과 최적수송 + Kun Zhang 참여 |
| XTransferCDR (Liu & Jin 2024) | run_08 루프백 | 도메인 분리 인코더 + 교차 전이 |
| Pacalin et al. (2025, Nature Biotech) | run_06 리뷰 | CRISPRai 가법 합 잔차로 GI 분류 → 최근접 선행 |

**왜 누락되었나:**
- run_04의 "10개 교차 도메인 스캔"이 breadth-first였고, depth-first 검증이 불충분
- "5개 용어 체계 + 30+ 백그라운드 쿼리"로 충분하다고 판단했으나, 용어 체계 자체가 편향
- arXiv 2025-2026 신규 논문을 실시간 추적하지 못함 (C3TL, BuDDI 등)

### 1.3 구조적 원인

```
문헌 리뷰의 구조적 문제:

1. 도메인 내 검색 → "경쟁자 0개" (거짓 안심)
2. 도메인 간 검색 누락 → 일반적 원리의 선행을 놓침
3. "0 경쟁자"에 기반한 프레이밍 → novelty 과대평가
4. 실험 실패 후 루프백에서야 누락 발견 → 방향 전환 비용 증가
```

**개선 방안:**
- "아이디어 추상화" 단계 추가: 연구 아이디어를 가장 추상적인 형태로 표현 후 타 도메인에서 검색
  - 예: "잔차→에피스태시스" → "모델 근사 잔차→누락된 구조" → Tan(2018), Diamond(2024) 즉시 발견
- "경쟁자 N개" 주장은 검색 공간의 너비를 명시해야: "섭동 생물학 내 0개, ML 전체 2개, 통계학 일반 원리 확립"
- novelty 평가 시 "적용 독창성"과 "아이디어 독창성"을 분리 평가

## 2. 구조적 문제: Novelty 평가의 체계적 편향

### 2.1 New Novelty Inflation (점진적 하향)

| 시점 | 주장 | 근거 | 실제 |
|------|------|------|------|
| run_06 (04-28) | "잔차→에피스태시스 경쟁자 0개" | 5개 용어 체계 검색 | 섭동 생물학 내만. Pacalin 누락 |
| run_09 (04-29) | "★★★★★ novelty" | 경쟁자 0개 기반 | Tan/Diamond/MoCHI 미발견 |
| 2차 스캔 (04-29) | "★★★★☆" | Tan/Diamond 발견 | "아이디어 자체는 일반적 원리" 인정 |
| 현재 | "30-40% 출판 가능성" | 통합 재평가 | 35-45%에서 하향 |

**패턴:** novelty 평가가 항상 초기에 과대→실험 후 과소. 이는 **확인 편향(confirmation bias)**의 구조적 발현.

### 2.2 "통합 = Novelty"의 함정

"FCR-ICM만이 6개 기능을 동시에 제공" → "이 통합성 자체도 novelty"

이 주장의 약점:
- 각 개별 기능의 novelty가 낮으면, 통합만으로는 부족
- 특히 Diamond가 "ML 모델에서 비가법적 효과 탐지 + FDR 제어"를 이미 수행
- 통합 novelty가 인정되려면 개별 기능 간 **비자명한 시너지**가 필요
- 현재 ICM→잔차 분해 가능성의 연결고리는 실험적으로 입증되었으나, "비자명성"은 주관적

### 2.3 Novelty 평가의 구조적 개선

```
개선된 novelty 평가 체계:

Layer 0: 아이디어의 가장 추상적 형태를 식별
         → "가법 모델 잔차 = 비가법적 신호" (통계학의 기본 교리)
         → 이 레이어에서 novelty = 0임을 먼저 인정

Layer 1: 아이디어의 도메인 특화 적용
         → 섭동 생물학에서 예측 잔차→에피스태시스
         → novelty = 적용 독창성 (★★★★★)

Layer 2: 방법론적 차별화
         → FCR 분해로 잔차 원천 식별, ICM 정규화가 전제조건
         → novelty = 방법 독창성 (★★★★☆)

Layer 3: 통합 시너지
         → 6개 기능의 비자명한 연결
         → novelty = 통합 독창성 (★★★☆☆ — 비자명성 입증 필요)
```

## 3. 구조적 문제: 가설-실험-프레이밍의 순환적 피벗

### 3.1 피벗 체인

```
NAP(GNN+XGBoost) → 실패(GNN 중복) → AL → 실패(AL<random) 
→ FCR-ICM(교세포 전이) → 부분성공(R2+0.10만) → 에피스태시스+UQ 
→ 부분성공(RQ2 미달→달성) → 현재
```

**구조적 문제:** 각 피벗이 **이전 실패의 원인이 아니라 결과**에 의해 구동됨
- GNN 실패 → "GNN 없이도 되네" (원인 분석이 아닌 결과 수용)
- AL 실패 → "AL은 안 되네" (AL이 왜 안 되는지보다 다음 방향으로)
- 교세포 전이 +0.10 → "novelty 불충분" (성능은 충분한데 novelty가 문제)

### 3.2 "성공의 역설"

run_04-07에서 FCR-ICM은 **기술적으로 성공**:
- RQ1: ICM이 z_tx 불변성 0.50→0.97 (합성), -0.35→0.35 (실제)
- RQ3: 교세포 전이 R2 -0.30→0.92 (극적)

그러나 이 성공이 **논문으로 가는 길을 막음**:
- 교세포 전이만으로는 BuDDI, C3TL과 중복 (+0.10 R2만 우위)
- 성공한 실험이 다음 방향(에피스태시스)의 근거가 되었으나, 에피스태시스는 다른 경쟁자들이 이미 탐색
- **기술적 성공과 novelty 성공의 분리** — 이것이 프로젝트의 근본적 딜레마

### 3.3 실험 우선 vs Novelty 우선

| 접근 | 문제 |
|------|------|
| 실험 우선: "잘 되는 것부터 하자" | 잘 되는 것이 이미 누군가 했던 것일 수 있음 |
| Novelty 우선: "새로운 것부터 하자" | 새로운 것이 잘 안 될 수 있음 (RQ2 미달) |
| 현재: 실험 성공 → novelty 재평가 → 하향 | 양쪽의 최악을 결합 |

**개선:** 프레이밍 단계에서 novelty 최대 평가를 먼저 완료한 후 실험 진입. "0 경쟁자" 주장은 2개 독립 검색 체계로 교차 검증 필수.

## 4. 구조적 문제: 평가 지표와 타겟 설정

### 4.1 RQ2 타겟 rho>0.6의 문제

- **설정 근거:** "publishable하려면 0.6 이상 필요" — 주관적 기준
- **실제:** Norman 0.401, Replogle 0.660 — 데이터셋 의존적
- **근본 문제:** MC Dropout 분산과 예측 오차의 Spearman rho가 **UQ의 적절한 지표인지** 자체가 불확실
  - MC Dropout은 모델의 **인식적 불확실성(epistemic uncertainty)**을 측정
  - 예측 오차는 **총 오차**(인식적+우발적+모델 편향)
  - 두 양의 상관이 완벽할 수 없음 (우발적 노이즈가 끼어듦)
  - rho=0.66이 "좋은" 것인지 "나쁜" 것인지에 대한 이론적 기준 부재

### 4.2 OOD Distance의 비견고성

| 데이터셋 | OOD rho | 해석 |
|----------|---------|------|
| Norman | +0.385 | 유의미한 양의 상관 |
| Replogle | -0.340 | 유의미한 음의 상관 |

**근본 원인:** OOD distance의 정의가 데이터 구조에 민감
- Norman: double-KO가 있어 "학습 분포에서 먼 조합"과 "예측이 어려운 조합"이 일치
- Replogle: 단일 섭동만 있어 모든 composed pair가 동등하게 OOD → OOD가 차별적 정보 없음
- **구조적 교훈:** UQ 신호의 유효성이 데이터셋 구조에 의존한다면, 단일 신호가 아닌 **신호 앙상블**이 필요

### 4.3 AUROC=1.0의 순환성

- RQ3에서 가법 잔차로 에피스태시스를 정의하고, 같은 잔차로 AUROC를 계산
- 이는 tautology: "잔차가 큰 것 = 에피스태시스"를 정의하고, "에피스태시스가 잔차가 크다"를 증명
- Product-GT rho=0.620으로 대체 가능했으나, 근본적으로 "에피스태시스의 ground truth가 무엇인가?"가 미해결

## 5. 구조적 문제: 모델-의존적 결과의 일반화 불가

### 5.1 결과의 모델 의존성

현재 모든 결과가 **단일 VAE 아키텍처**에 의존:
- z_dim=8, 3-분해(z_x/z_t/z_tx), 인코더 2층 MLP, 디코더 3층 MLP
- ICM MMD 정규화 (sigma=1.0, icm_weight=10.0)
- MC Dropout (p=0.1)

이 설정이 바뀌면:
- RQ1/RQ3의 절대값 변동 가능 (z_dim, icm_weight에 민감)
- RQ2 rho 변동 가능 (MC Dropout p, 디코더 깊이에 민감)
- 에피스태시스 분해의 질 변동 가능 (인코더 용량에 민감)

### 5.2 하이퍼파라미터 튜닝 부재

- icm_weight=10.0: run_04에서 임의 설정, 튜닝 없음
- z_dim=8: FCR 원논문 기본값
- MC Dropout p=0.1: 표준값
- 150 epochs: 조기 종료 없이 고정

**구조적 문제:** "논문급 결과"를 주장하면서 하이퍼파라미터 튜닝이 없다는 것은 결과의 견고성에 대한 의문을 피할 수 없음. 특히 RQ2 rho=0.660이 icm_weight나 MC p에 민감하다면, 결과의 일반성이 약해짐.

## 6. 구조적 문제: 실데이터 검증의 근본적 한계

### 6.1 에피스태시스 분해의 검증 불가

합성 데이터에서는 r=1.000 (완벽)이나, 실데이터에서는:
- Ground truth 성분(r_epistasis vs r_model vs r_noise)이 없음
- 간접 검증만 가능: OOD, MC Dropout, Cross-CT 일관성
- MoCHI(단백질 DMS)는 biophysical model 기반으로 ground truth가 있음
- **이것은 이 연구 방향의 근본적 한계** — 잔차 분해의 "정확도"를 직접 증명할 방법이 없음

### 6.2 PORTAL 665K 쌍의 미활용

- PORTAL(2026)의 대규모 GI 맵이 검증 기회를 제공하나:
  - 데이터 접근성 불확실 (bioRxiv preprint, 공개 데이터셋 여부 미확인)
  - 단백질 안정성이 아닌 세포 성장 기반 GI → 직접 비교 가능성
  - 665,856 쌍으로 precision/recall 평가 이론적 가능
- **구조적 문제:** "가장 중요한 검증"이 항상 "다음 단계"로 미뤄짐

## 7. 종합: 5개 구조적 원인과 개선 방안

| # | 구조적 원인 | 증상 | 개선 방안 |
|---|-----------|------|----------|
| 1 | **교차 도메인 문헌 검색 누락** | "경쟁자 0개" 과대주장 → 하향 | 아이디어 추상화→타도메인 검색 의무화 |
| 2 | **Novelty 확인 편향** | 초기 ★★★★★→점진 하향 | "0 경쟁자" 주장 시 2체계 교차 검증 |
| 3 | **실험-프레이밍 순환 피벗** | 성공→novelty 불충분→방향 전환 | novelty 최대 평가를 실험 선행 |
| 4 | **평가 지표의 비견고성** | OOD rho +0.39→-0.34 (데이터셋 의존) | 단일 지표 의존 배제, 신호 앙상블 |
| 5 | **실데이터 검증 불가** | 합성 r=1.000 vs 실제 black box | 간접 검증 체계(consistency, cross-CT, ablation)를 명시적 방법론으로 격상 |

## 8. 현재 프로젝트 상태에 대한 정직한 평가

### 8.1 확실히 입증된 것

1. **ICM 정규화가 z_tx 불변성에 유효** (RQ1, 2개 데이터셋, 합성+실제)
2. **ICM이 교세포 zero-shot 전이에 결정적** (RQ3, R2 -0.30→0.92)
3. **MC Dropout이 단일 섭동 UQ에 유효** (Replogle rho=0.660)
4. **에피스태시스 기반 AL이 random 대비 5.0x 개선** (RQ4, 2개 데이터셋 일치)
5. **에피스태시스는 스펙트럼** (이진이 아닌 연속적)

### 8.2 확실히 약한 것

1. **아이디어 독창성**: "잔차→비가법 신호"는 일반적 원리. 차별화는 적용+분해 구조
2. **OOD distance**: 데이터셋 의존적, Replogle에서 무효
3. **에피스태시스 분해의 실데이터 검증**: 불가능 (ground truth 없음)
4. **Cross-CT 에피스태시스 일관성**: rho=0.444, 방향 일치 59% (강하지 않음)
5. **하이퍼파라미터 견고성**: 미검증

### 8.3 논문 가능성 재평가

| 기준 | 현재 상태 | 비고 |
|------|----------|------|
| Novelty | ★★★☆~★★★★ | 아이디어는 일반적, 적용+분해는 새로움 |
| Soundness | ★★★★ | 합성 검증 완료, 실데이터 간접 검증 |
| Significance | ★★★ | 실제 생물학적 임팩트 미증명 |
| Completeness | ★★★ | RQ2 달성, OOD 비견고, 단일 아키텍처 |
| Reproducibility | ★★★★★ | 공개 데이터, 코드 완비 |

**출판 가능성: 30-40%** (NeurIPS/ICML workshop, ISMB, RECOMB)
- 하향 압력: 아이디어 독창성 한계, 실데이터 검증 불가, OOD 비견고
- 상향 압력: RQ2 달성, 교세포 전이 극적 개선, AL 5.0x, 통합 프레임워크

### 8.4 출판 가능성을 높이려면

1. **FDR 제어 추가** (Diamond 대비 차별화): 잔차 분해에 knockoff/순열 검정 적용
2. **PORTAL 대규모 검증**: 665K 쌍으로 precision/recall 정량화
3. **하이퍼파라미터 견고성 입증**: icm_weight, z_dim, MC p에 대한 민감도 분석
4. **다중 아키텍처 검증**: FCR 외 다른 분해 모델(CPA, BuDDI)에서도 잔차 분해 유효한지
5. **포지셔닝 수정**: "아이디어가 새롭다"가 아닌 "적용+분해+전제조건(ICM)의 통합이 새롭다"
