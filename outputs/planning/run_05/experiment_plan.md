## 1. 방법론 아키텍처 (6-Phase, 수정)

```
Phase 1: FCR-ICM 모델 학습 (K562 + RPE1 각각) — 기존과 동일
Phase 2: 조합 예측 + 잔차 추출 (각 세포유형별) — 기존과 동일
Phase 3: 잔차 분해 (r_epistasis + r_model + r_noise) — 기존과 동일
Phase 4: 불확실성 정량화 (MC Dropout ONLY, ICM 위반 제거) — 수정
Phase 5: 에피스태시스 점수 산출 (각 세포유형별, 3-공식 민감도) — 기존과 동일
Phase 6: 잔차 순위 교세포 전이 + 능동학습 (RQ3+RQ4) — 수정 (ICM→잔차 순위)
```

### Phase 4 변경 상세
- **제거**: ICM 위반 점수 (run_11에서 UQ weight=0.0으로 무효 확인)
- **유지**: MC Dropout 분산 (Replogle rho=0.660으로 유효)
- **결과**: UQ = MC Dropout 단일 신호원

### Phase 6 변경 상세
- **제거**: ICM 정렬 z_tx 기반 전이 (A1 방식, run_11에서 A7보다 열위)
- **채택**: 잔차 순위 전이 (A7 방식, run_11 최고 rho=0.402)
- **유지**: 불확실성 기반 AL (4-8× 개선 확인)

## 8. 사용자 컨펌 필요 항목

1. **잔차 순위 전이(A7)를 주 전이 방법으로 채택** — ICM 전이보다 실험적으로 우수하나, "단순한 방법"이라 novelty가 약화될 수 있음

3. **MC-only UQ** — ICM 위반 결합 제거, 단일 신호원
4. **PORTAL 외부 검증 포함 여부** — 데이터 접근성 불확실
