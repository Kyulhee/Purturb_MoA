## 2. 새 프레이밍 방향 검토

- **스토리**: "Perturb-seq 조합 예측의 불확실성 정량화와 능동학습"
- **장점**: RQ2 PASS(rho=0.660), RQ4 PASS(5.0x) — 검증된 결과
- **단점**: "에피스태시스" 이야기가 빠지면 novelty가 약해짐. 잔차 분해(RQ1)가 무엇을 위한 것인지 동기가 약해짐
- **판정**: 가능하나 약함

### 옵션 B: RQ3을 "교세포 에피스태시스 전이 예측"으로 재정의 ★

- **새 RQ3**: "한 세포유형에서 관측한 에피스태시스 패턴으로, 새 세포유형에서 에피스태시스가 발생할 조합을 예측할 수 있는가?"
- **핵심 변화**: 탐지(detection) → 전이 예측(transfer prediction)
- **순환 회피**: K562 에피스태시스로 RPE1 에피스태시스 예측. ground-truth(RPE1)가 예측 신호(K562)와 독립
- **기존 데이터**: rho=0.444, overlap=0.65 (run_10 예비 결과)
- **ICM과 자연스러운 연결**: ICM이 z_tx 교세포 정렬→에피스태시스도 교세포 전이 가능
- **실용적 의미**: 새 세포유형에서 실험 우선순위 결정
- **판정**: **채택**

### 옵션 C: RQ3을 "에피스태시스 특성화"로 재정의

- **새 RQ3**: 에피스태시스의 유형/강도/공식 민감도 분석
- **장점**: 순환 문제 회피
- **단점**: 탐지/예측 능력을 입증하는 게 아니라 기술적 분석에 머묾. top venue에 부족
- **판정**: 보완적 결과로는 좋으나 핵심 RQ로는 약함

## 3. 채택된 새 프레이밍

### 핵심 아이디어

**기존**: 잔차에서 에피스태시스를 탐지 (동어반복)
**새로**: 에피스태시스는 세포유형 간에 부분적으로 보존되며, 한 세포유형의 에피스태시스 패턴과 불확실성으로 새 세포유형의 에피스태시스를 예측할 수 있다

이것이 성립하려면:
1. 에피스태시스가 세포유형 간에 보존되는 정도가 우연보다 높아야 함 (rho=0.444 > 0, run_10 확인)
2. ICM 정규화가 이 전이를 개선해야 함
3. 불확실성 기반 AL이 교세포 에피스태시스 탐지 효율을 개선해야 함

### 새 연구 질문

**"인과 불변성 기반 섭동 표현(z_tx)의 조합 예측 불확실성을 정량화할 때, (1) 불확실성이 조합 예측의 신뢰도를 유전자별·섭동별로 정량화할 수 있는가? (2) 한 세포유형의 에피스태시스 패턴과 불확실성으로 새 세포유형에서 에피스태시스가 발생할 조합을 예측할 수 있는가? (3) 불확실성 기반 능동학습이 교세포 에피스태시스 탐지 효율을 개선하는가?"**

### 새 하위 질문

1. **RQ1 (잔차 분해)**: 조합 섭동 예측 잔차를 에피스태시스 신호 vs 모델 오차 vs 노이즈로 원칙적으로 분해할 수 있는가?
   - 변화 없음. 합성 검증 완료 (r=1.000). 기반 작업으로 유지

2. **RQ2 (불확실성 정량화)**: MC Dropout + ICM 위반 점수를 결합하여 섭동 예측의 신뢰도를 정량화할 수 있는가?
   - 변화: OOD distance 제거 (Replogle에서 무효 확인). MC Dropout을 주 신호원으로
   - 기존 결과: Replogle rho=0.660 PASS

3. **RQ3 (교세포 에피스태시스 전이)**: 한 세포유형에서 관측한 에피스태시스 패턴으로, 새 세포유형에서 에피스태시스가 발생할 조합을 zero-shot으로 예측할 수 있는가?
   - **핵심 변화**: 탐지(detection) → 전이 예측(transfer prediction)
   - 순환 불가능: ground-truth(타겟 세포유형)가 예측 신호(소스 세포유형)와 독립
   - 예비 근거: rho=0.444, overlap=0.65, direction agreement=59%

4. **RQ4 (능동학습)**: 불확실성 기반 획득 함수가 교세포 에피스태시스 탐지에서 랜덤 대비 효율을 개선하는가?
   - 변화: "에피스태시스 탐지" → "교세포 에피스태시스 탐지"
   - 기존 결과: 5.0x PASS, transfer overlap=0.65
