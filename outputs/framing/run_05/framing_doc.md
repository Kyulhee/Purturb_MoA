**"조합 섭동 예측 잔차에서 에피스태시스를 분해할 때, (1) 잔차를 에피스태시스/모델 오차/노이즈로 원칙적 분해가 가능한가? (2) MC Dropout 기반 불확실성이 섭동 예측의 신뢰도를 유전자별·섭동별로 정량화할 수 있는가? (3) 에피스태시스가 세포유형 간에 부분 보존되어, 단순 잔차 순위로도 교세포 전이 예측이 가능한가? (4) 불확실성 기반 능동학습이 교세포 에피스태시스 탐지 효율을 개선하는가?"**

2. **RQ2 (불확실성 정량화)**: MC Dropout 분산으로 섭동 예측의 신뢰도를 유전자별·섭동별로 정량화할 수 있는가? (ICM 위반 결합 제거, MC-only)
3. **RQ3 (에피스태시스 교세포 보존)**: 에피스태시스가 세포유형 간에 부분 보존되어, 단순 잔차 순위 전이로 새 세포유형의 에피스태시스를 예측할 수 있는가? (ICM→잔차 순위로 전이 방법 변경)
4. **RQ4 (능동학습)**: 불확실성 기반 획득 함수가 교세포 에피스태시스 탐지에서 랜덤 선택 대비 효율을 개선하는가? (변화 없음)

## 5. ICM의 재배치

ICM을 완전히 배제하지는 않음. 단 **주 가설의 핵심 기구**에서 **보조적 역할**으로 강등:

| 역할 | 상태 | 근거 |
|------|------|------|
| z_tx 분포 정렬 → 교세포 예측 전이 | 유효 | run_07: R2 -0.30→0.92 |
| z_tx 분포 정렬 → 에피스태시스 전이 | **무효** | run_11: ICM 개선율 0.966× |
| ICM 위반 = 불확실성 | **무효** | UQ weight=0.0 |
| z_tx 불변성 자체 | 유효 (합성+실제) | RQ1 기반 |

**논문에서의 ICM 포지셔닝:**
- "FCR 분해의 정규화 방법으로 ICM을 도입하면, z_tx의 교세포 정렬이 개선되어 일반적인 섭동 예측 전이는 크게 향상된다(R2 -0.30→0.92). 그러나 에피스태시스 전이에는 ICM이 부정적이며, 이는 MMD 정규화가 세포유형 특이적 에피스태시스 신호를 제거하기 때문이다."
- 이 결과 자체가 **부정적 결과(negative result)로서 가치** — "ICM이 일반 전이에 유효하나 에피스태시스 전이에 무효"라는 발견
