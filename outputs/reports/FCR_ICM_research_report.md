# FCR-ICM: 인과 불변성 원리로 제약된 인자화 표현을 통한 Perturb-seq 조합 예측

**작성일:** 2026-04-27 | **상태:** 진행 중 (RQ1/RQ3 실제데이터 검증 전)

---

## TL;DR

**질문:** 단일 유전자 교란(knockout) 데이터만으로, 다른 세포유형에서의 조합 교란 효과를 제로샷으로 예측할 수 있는가?

**방법:** VAE 기반 FCR 인코더로 섭동 효과를 z_tx 잠재변수로 분해하고, ICM 원리의 MMD 정규화로 z_tx를 세포유형 불변으로 만든 뒤, 불변 z_tx의 조합으로 조합 교란을 예측.

**주요 결과:**
| 연구질문 | 합성 데이터 | 실제 데이터 (Norman 2019) |
|----------|------------|--------------------------|
| RQ1: ICM이 z_tx를 세포유형 불변으로 만드는가? | 교세포 상관계수 0.50 → **0.97** | 다세포유형 데이터 필요 |
| RQ2: 단일-KO z_tx로 조합 예측이 가능한가? | 유전자공간 R2 = **0.88** | corr = **0.955**, R2 = **0.881** |
| RQ3: ICM이 제로샷 교세포 전이를 가능하게 하는가? | 교세포 상관계수 0.51 → **0.96** | 다세포유형 데이터 필요 |

**결론:** ICM은 불변성/전이에 확실히 유효하다. 조합성은 유전자 공간에서 평가해야 하며, 이때 baseline FCR만으로 R2=0.88에 도달한다. RQ1/RQ3의 실제데이터 검증이 남은 핵심 과제다.

## 1. 서론: 왜 이 연구를 하는가

### 1.1 Perturb-seq란?

Perturb-seq[^1]는 CRISPR-Cas9 유전자 교란(knockout, KO)과 단일세포 RNA 시퀀싱(single-cell RNA-seq, scRNA-seq)을 결합한 기술이다. 각 세포에 특정 유전자를 파괴하는 가이드 RNA(sgRNA)를 도입한 뒤, 전체 전사체를 측정하여 "이 유전자를 없애면 세포의 발현 패턴이 어떻게 변하는가"를 단일세포 해상도로 관찰한다.

이 기술로 수천 개의 유전자 교란 효과를 동시에 프로파일링할 수 있지만, 두 가지 근본적 한계가 있다.

### 1.2 두 가지 미해결 문제

**문제 1: 조합 폭발(Combinatorial Explosion).** 생물학적 실험에서는 한 번에 하나의 유전자만 교란하는 단일 KO(single knockout)가 일반적이다. 그러나 실제 질병은 여러 유전자의 조합적 변이에서 비롯되며, 이중 KO(double knockout) 실험은 조합 수가 폭발적으로 증가한다. 예를 들어 131개 단일 KO가 가능한 유전자 세트에서 이중 KO 조합은 131×130/2 = 8,515가지다. 모든 조합을 실험하는 것은 불가능에 가깝다. 따라서 **단일 KO 데이터만으로 조합 교란 효과를 예측**하는 것이 핵심 도전 과제다.

**문제 2: 교차 세포유형 전이(Cross-Cell-Type Transfer).** 대부분의 Perturb-seq 연구는 단일 세포유형(예: K562 백혈병 세포주)에서 수행된다. 그러나 같은 유전자 교란이 폐 세포, 간 세포, 신경 세포에서는 다른 효과를 낼 수 있다. 매 세포유형마다 새로운 Perturb-seq 실험을 수행하는 것은 비용과 시간 측면에서 비현실적이다. **한 세포유형에서 학습한 모델을 다른 세포유형에 제로샷(zero-shot)으로 전이**하는 것이 두 번째 도전 과제다.

### 1.3 기존 방법의 한계

| 방법 | 접근 방식 | 조합 예측 | 교차 세포유형 전이 | 한계 |
|------|----------|----------|-------------------|------|
| GEARS[^2] | GNN + 유전자조절네트워크 | 조합 학습 데이터 필수 | 명시적으로 미지원 | 조합 데이터 없으면 예측 불가 |
| CPA[^3] | 조합 오토인코더 | OOD[^4] 시 DEG[^5] 0.85→0.38 급락 | 제한적 | 분포 밖 일반화 실패 |
| SAMS-VAE | 희소 가법 메커니즘 | 가법 가정만 | - | 유전자 간 상호작용 표현 불가 |
| MapPFN | 인컨텍스트 학습 | 제로샷 가능 | - | 명시적 조합 구조 없음 |

핵심 갭(gap): **인과 불변성과 조합성의 교차점이 미탐색**이다. FCR은 분해된 표현을 제공하나 교차 세포유형 전이에 적용하지 않았고, ICM은 이론 원리이나 섭동 예측의 정규화로 사용된 적 없다. 이 둘의 결합은 새로운 연구 공간이다.

### 1.4 연구 질문

**"FCR을 ICM 원리로 정규화했을 때, 섭동 효과가 세포유형에 걸쳐 불변하는 인과 모듈로 분해되며, 이 모듈들의 조합이 타겟 세포유형의 학습 데이터 없이 조합 섭동 효과를 예측할 수 있는가?"**

하위 질문 세 가지:

1. **RQ1 (불변성):** ICM 정규화된 z_tx가 세포유형 간에 불변(invariant)인가?
2. **RQ2 (조합성):** 단일-KO z_tx로 조합적 예측이 가능한가?
3. **RQ3 (제로샷 전이):** ICM이 zero-shot 교세포 전이를 가능하게 하는가?

## 2. 이론적 배경

### 2.1 표현 학습(Representation Learning)

단일세포 발현 데이터는 보통 2만 개 이상의 유전자 차원을 가진다. 표현 학습은 이 고차원 데이터를 저차원 잠재 공간(latent space)으로 압축하여 데이터의 본질적 구조를 포착한다. 변분자동인코더(Variational Autoencoder, VAE)[^6]가 대표적 방법으로, 인코더가 관측 데이터를 잠재변수 z로 압축하고 디코더가 z에서 원래 데이터를 복원하는 구조다. 이 과정에서 z는 "데이터를 생성한 숨겨진 요인"을 포착하도록 학습된다.

### 2.2 인과 표현 학습(Causal Representation Learning)

일반 표현 학습이 "의미 있는" 잠재변수를 찾는다면, 인과 표현 학습[^7]은 "인과적인" 잠재변수를 찾는다. 인과적이라는 것은, 데이터 생성 환경이 변하더라도(예: 세포유형이 바뀌어도) 일관되게 작동한다는 뜻이다. 상관관계는 환경이 바뀌면 무너질 수 있지만, 인과관계는 환경에 걸쳐 안정적이라는 철학이다. 이것이 본 연구에서 "불변성(invariance)"을 추구하는 이론적 근거다.

### 2.3 FCR: Factorized Causal Representations

FCR(Mao et al., 2024)[^8]은 관측 데이터를 세 가지 의미론적 잠재변수로 분해한다:

- **z_x (공변량, covariate):** 세포유형, 세포주기 등 처리와 무관한 세포 특이 정보. "이 세포가 어떤 상태인가?"에 해당
- **z_t (처리 식별자, treatment identifier):** 어떤 유전자가 KO되었는지. "어떤 교란이 가해졌는가?"에 해당
- **z_tx (상호작용 효과, interaction effect):** 해당 처리가 이 세포에 미치는 실제 효과. "이 교란이 이 세포에서 무슨 일을 일으키는가?"에 해당

**직관적 비유:** z_x는 환자의 기저 체질, z_t는 투여한 약의 종류, z_tx는 그 약이 그 환자에게 미치는 실제 효과에 해당한다. 같은 약(z_t)을 다른 환자(z_x)에게 투여하면 효과(z_tx)가 달라질 수 있다. 그러나 ICM 가설에 따르면, 약의 작용 메커니즘 자체는 환자와 무관해야 한다 — 이것이 다음 절의 주제다.

이 분해의 이론적 장점은 block-wise identifiability[^9]다. 적절한 가정 하에서 각 잠재변수가 진짜 의미론적 요인까지 식별 가능함이 증명되어 있다. 즉, z_tx가 실제 교란 효과와 대응된다는 보장이 있다.

### 2.4 ICM: Independent Causal Mechanisms

ICM 원리[^10]는 "인과 메커니즘은 맥락(context)에 독립적이다"라고 주장한다.

**직관적 설명:** 유전자 A를 KO했을 때의 인과적 효과(메커니즘)는, 그 KO가 K562 세포에서 일어났는지 RPE1 세포에서 일어났는지와 무관해야 한다. 물론 최종 발현 변화는 세포유형에 따라 다를 수 있다 — 그러나 그것은 z_x(기저 발현)가 다르기 때문이지, z_tx(교란 효과 메커니즘) 자체가 다르기 때문이 아니라는 것이 ICM의 주장이다.

다시 비유로 돌아가면: 해열제의 작용 메커니즘(체온 조절 중추 억제)은 환자와 무관하다. 다만 환자의 기저 체온, 체중 등에 따라 최종 효과의 크기는 달라질 수 있다.

이 원리는 IEM(Interchangeable Ensembles of Mechanisms)[^11]에서 교환 가능 메커니즘으로 형식화되었다.

**핵심 추론:** z_tx가 진짜 인과적 교란 효과를 포착한다면, ICM 원리에 따라 z_tx는 세포유형에 불변이어야 한다. 즉, 같은 교란에 대해 다른 세포유형에서 얻은 z_tx가 비슷한 분포를 가져야 한다.

### 2.5 MMD: Maximum Mean Discrepancy

MMD는 두 확률 분포가 같은지 다른지를 검정하는 방법이다. 두 분포의 표본을 커널 함수(가우시안 RBF 등)로 고차원 공간에 매핑한 뒤, 그 공간에서의 평균 차이를 측정한다. MMD = 0이면 두 분포가 같고, 값이 클수록 다르다.

**직관적 설명:** 두 그룹의 z_tx를 고차원 공간에 펼쳐놓고, 각 그룹의 무게중심이 얼마나 떨어져 있는지를 측정한다고 생각하면 된다. 무게중심이 가까우면 두 분포가 비슷하고, 멀면 다르다.

본 연구에서는 MMD를 정규화 항으로 사용하여, 서로 다른 세포유형에서 얻은 z_tx 분포를 정렬한다. MMD가 0에 가까워지도록 학습하면, 두 세포유형의 z_tx가 같은 분포를 갖게 되어 ICM 불변성이 실현된다.

## 3. 방법론: FCR-ICM 파이프라인

### 3.1 전체 아키텍처

```
입력: 단일세포 발현 벡터 x + 교란 식별자 t + 세포유형 c

    ┌─────────────────────────────────────┐
    │  Module 1: FCR 인코더               │
    │  q(z|x, t, c) → z_x, z_t, z_tx     │
    └──────────────┬──────────────────────┘
                   │
    ┌──────────────▼──────────────────────┐
    │  Module 2: ICM 정규화               │
    │  L_ICM = MMD(z_tx^A, z_tx^B)       │
    │  → z_tx를 세포유형 불변으로 정렬     │
    └──────────────┬──────────────────────┘
                   │
    ┌──────────────▼──────────────────────┐
    │  조합 예측 (RQ2)                     │
    │  z_tx_combo = z_tx_A + z_tx_B (가법) │
    │  또는 z_tx_A ⊙ z_tx_B (승법)        │
    └──────────────┬──────────────────────┘
                   │
    ┌──────────────▼──────────────────────┐
    │  디코더 p(x|z_x, z_t, z_tx)         │
    │  → 유전자 공간에서 평가               │
    └─────────────────────────────────────┘
```

### 3.2 Module 1: FCR 인코더

FCR 인코더는 VAE 구조를 가지며, 입력 (x, t, c)를 세 잠재변수로 인코딩한다:

- **z_x 인코더:** q(z_x | x) — 교란과 무관한 세포 특이 공변량
- **z_t 인코더:** q(z_t | t) — 교란 식별자의 임베딩
- **z_tx 인코더:** q(z_tx | x, t) — 교란 효과 (가장 중요한 변수)

디코더는 p(x | z_x, z_t, z_tx)로 원래 발현 벡터를 재구성한다. 학습은 표준 VAE 손실(재구성 오차 + 정규화 항)로 이루어진다. 재구성 항은 "디코딩된 결과가 원래 데이터와 얼마나 비슷한가"를 측정하고, 정규화 항은 "잠재변수가 너무 극단적인 값을 갖지 않도록" 통제한다.

### 3.3 Module 2: ICM 정규화

ICM 원리를 구현하기 위해, 서로 다른 세포유형 A, B에서 얻은 z_tx 분포를 MMD로 정렬한다. 학습 손실에 다음 항을 추가한다:

> L_ICM = MMD(z_tx from cell type A, z_tx from cell type B)

같은 교란 t에 대해 세포유형 A와 B에서 얻은 z_tx가 비슷해지도록 강제한다. 이 정규화가 없으면 z_tx에 세포유형 정보가 누설되어, z_tx는 교란 효과와 세포유형 정보가 뒤섞인 표현이 된다.

**ICM의 부차적 효과:** MMD 정규화는 z_tx의 분포를 정돈하는 효과가 있다. 비선형 인코더가 자유롭게 z_tx를 매핑하는 것을 제약하여, 결과적으로 인코더가 더 선형적으로 작동하게 만든다. 이는 조합 구조 보존에 간접적으로 기여한다.

### 3.4 조합 예측

단일 KO로 얻은 z_tx_A, z_tx_B를 조합하여 이중 KO 효과를 예측한다:

- **가법 조합(additive):** z_tx_combo = z_tx_A + z_tx_B — 독립 경로에 적합
- **승법 조합(multiplicative):** z_tx_combo = z_tx_A ⊙ z_tx_B — 같은 경로 내 상호작용에 적합

**직관적 설명:** 유전자 A KO가 발현에 +2의 효과를, 유전자 B KO가 +3의 효과를 준다면, 두 KO를 동시에 하면 +5의 효과가 나는가? 이것이 가법 조합의 가정이다. 실제로는 두 경로가 같은 하위경로를 공유하면 가법이 성립하지 않을 수 있다(상위성, epistasis).

조합된 z_tx_combo를 디코더에 통과시켜 유전자 발현 예측값을 얻고, 실제 이중 KO 발현 데이터와 비교한다.

**중요:** 조합성은 **유전자 공간(gene space)**에서 평가해야 한다. 잠재 공간(latent space)에서의 평가는 인코더의 비선형성 때문에 조합 구조가 파괴되어 보일 수 있다 (5.2.1절에서 상세 논의).

### 3.5 소거실험 설계

각 구성요소의 기여도를 측정하기 위해 6가지 구성을 비교한다:

| # | 구성 | ICM | Linear z_tx head | Comp loss | 목적 |
|---|------|-----|------------------|-----------|------|
| 1 | FCR baseline | - | - | - | 기준선 |
| 2 | FCR + ICM | O | - | - | ICM 효과 |
| 3 | FCR + linear head | - | O | - | 선형성 효과 |
| 4 | FCR + ICM + linear | O | O | - | ICM + 선형성 |
| 5 | FCR + ICM + comp loss | O | - | O | ICM + 조합 정규화 |
| 6 | Full model | O | O | O | 전체 모델 |

- **Linear z_tx head:** z_tx 인코더의 마지막 층을 선형(비선형 활성화 없음)으로 교체하여 인코더 비선형성 감소 시도
- **Compositional consistency loss (comp loss):** 이중 KO 데이터를 이용해 "z_tx_A + z_tx_B가 z_tx_AB와 같아야 한다"는 제약을 학습 손실에 추가. 합성 데이터에서는 지면 진실(ground truth) z_tx가 있어 효과적이지만, 실제 데이터에서는 다른 결과를 보인다

| 데이터셋 | 세포유형 | 교란 유형 | 규모 | 용도 | 접근번호 |
|----------|----------|----------|------|------|----------|
| 합성 데이터 | 2가지 (가상) | 10개 교란 | n_genes=50 | RQ1/RQ2/RQ3 합성 검증 | - |

**Replogle 2022:** Genome-scale CRISPRi Perturb-seq. K562 외에 RPE1 세포주도 포함하나, 현재 RPE1 데이터 로딩에 실패하여 K562만 사용 중이다.

### 4.2 구현 세부사항

- 프레임워크: PyTorch
- 잠재변수 차원: z_dim = 8
- VAE β 가중치: 1.0 (기본)
- ICM 정규화: MMD with Gaussian RBF kernel
- 최적화: Adam, learning rate = 1e-3
- 학습 epoch: 100 (합성), 50 (실제)
- 전처리: Scanpy 표준 파이프라인 (정규화, 로그변환, HVG 500개 선택)

### 4.3 평가 지표

| 지표 | 설명 | 직관 |
|------|------|------|
| R2 (결정계수)[^15] | 예측값이 실제값을 얼마나 잘 설명하는가. 1이면 완벽, 0이면 평균 수준, 음수면 평균보다 못함 | "예측이 실제를 얼마나 잘 따라가는가" |
| Pearson 상관계수 | 두 변수의 선형 상관관계 (-1 ~ 1) | "예측과 실제의 방향이 얼마나 일치하는가" |
| 코사인 유사도 | 두 벡터의 방향 일치도 (0 ~ 1) | "잠재공간에서 두 표현이 같은 방향을 가리키는가" |
| 교세포 상관계수 | 다른 세포유형 간 z_tx의 상관관계 | RQ1 불변성의 핵심 지표 |

## 5. 결과

### 5.1 RQ1: ICM이 z_tx를 세포유형 불변으로 만드는가?

**합성 데이터:** ICM 정규화의 효과는 극적이다.

| 구성 | 교세포 상관계수 (z_tx) |
|------|----------------------|
| FCR (ICM 없음) | 0.505 |
| FCR + ICM | **0.971** |

ICM 없이는 z_tx에 세포유형 정보가 누설되어 다른 세포유형의 z_tx와 낮은 상관관계(0.505)를 보인다. ICM 정규화 후에는 같은 교란에 대해 두 세포유형의 z_tx가 거의 동일해진다(0.971). 10개 교란 모두에서 MMD 정규화가 개선을 보였다(개선 범위: +0.21 ~ +0.74).

**직관:** ICM이 없으면 모델이 "이 교란이 K562에서 어떤 효과를 내는가"와 "이 교란이 RPE1에서 어떤 효과를 내는가"를 서로 다르게 인코딩한다. ICM이 있으면 모델이 교란 효과의 본질(인과 메커니즘)을 세포유형과 분리하여 인코딩하게 된다.

**실제 데이터:** 다세포유형 Perturb-seq 데이터가 필요하여 아직 검증되지 않았다. Norman 2019는 단일 세포유형(K562)이므로 RQ1 검증에 사용할 수 없다.

### 5.2 RQ2: 단일-KO z_tx로 조합 예측이 가능한가?

이 질문은 본 연구에서 가장 흥미로운 발견을 낳았다.

#### 5.2.1 합성 데이터: 잠재공간 vs 유전자공간

| 평가 공간 | 평균 상관계수 | 평균 R2 |
|-----------|-------------|---------|
| 잠재 공간 (composed z_tx vs ground truth z_tx) | 0.476 | **0.047** |
| 유전자 공간 (decoded z_tx vs 실제 발현) | **0.941** | **0.881** |

잠재 공간에서는 조합이 거의 작동하지 않는다(R2=0.047). 그러나 디코더를 거쳐 유전자 공간에서 평가하면 R2=0.881로 급등한다.

**왜 이런 현상이 일어나는가?** 인코더는 비선형 매핑을 학습한다. 비선형 함수 f에 대해 f(a)+f(b) ≠ f(a+b)가 성립하는 것이 일반적이다. 잠재공간에서 f(a)+f(b)를 지면 진실 a+b와 직접 비교하면 당연히 맞지 않는다.

그러나 **디코더가 이 비선형성을 보상**한다. 인코더-디코더는 공동으로 학습되므로, decode(f(a)+f(b))가 실제 이중 KO 발현과 일치하도록 적응한다. 비유하자면: 인코더가 암호화하고 디코더가 복호화하는데, 암호화 과정에서 조합 구조가 뒤섞여도 복호화 후에는 원래 구조가 복원되는 것과 같다.

**함의:** 조합성은 반드시 출력 공간(유전자 발현)에서 평가해야 한다. 잠재 공간의 조합 구조가 깨져 보이는 것은 인코더의 비선형성 때문이며, 이는 디코더에 의해 보상된다. 잠재 공간에서 조합이 깨졌다고 해서 모델이 조합성을 학습하지 못한 것으로 결론 내리면 안 된다.

#### 5.2.2 실제 데이터 (Norman 2019)

| 구성 | best_corr | best_R2 | R2_add | R2_mul |
|------|-----------|---------|--------|--------|
| FCR baseline (no ICM) | 0.9552 | 0.8811 | 0.8806 | 0.8515 |
| FCR + ICM | 0.9538 | 0.8846 | 0.8827 | 0.8645 |
| FCR + linear z_tx | 0.9571 | 0.8844 | 0.8827 | 0.8545 |
| FCR + ICM + linear z_tx | 0.9561 | **0.8861** | **0.8855** | 0.8508 |
| FCR + ICM + comp loss | 0.9464 | 0.8631 | 0.8602 | 0.8288 |
| ICM + linear + comp loss | 0.9550 | 0.8740 | 0.8729 | 0.8288 |

**주요 발견:**

1. **모든 구성이 R2 = 0.86-0.89로 유사하다.** 합성 데이터에서 comp loss가 RQ2를 0.20→0.79로 극적으로 개선했지만, 실제 데이터에서는 이미 baseline이 R2=0.88에 도달해 있어 추가 개선 여지가 없다. 이는 Norman 데이터에서 FCR baseline의 조합성이 이미 천장 근처라는 것을 의미한다.

2. **Comp loss가 오히려 성능을 저하시킨다.** Config 5(ICM + comp loss)가 최저 R2=0.8631을 기록했다. 합성에서는 지면 진실 z_tx가 있어 "z_tx_A + z_tx_B = z_tx_AB"를 강제할 수 있지만, 실제에서는 그런 지면 진실이 없다. 인코더-디코더가 공동으로 자연스럽게 조합 표현을 학습하는데, comp loss가 이를 과도하게 제약하여 오히려 해가 된다.

3. **가법 조합이 86% 우위다.** 128개 이중 KO 쌍 중 110쌍(86%)에서 가법(z_tx_A + z_tx_B)이 승법(z_tx_A ⊙ z_tx_B)보다 우수했다. 이는 독립 경로의 교란이 발현 공간에서 가법적으로 결합한다는 생물학적 기대와 일치한다.

4. **최고 성능 쌍 (Config 4):** MAP2K6+ELMSAN1 (R2=0.945), BCL2L11+BAK1 (R2=0.943), MAP2K3+MAP2K6 (R2=0.944), KLF1+MAP2K6 (R2=0.941).

### 5.3 RQ3: ICM이 제로샷 교세포 전이를 가능하게 하는가?

**합성 데이터:**

| 구성 | 전이 상관계수 | 전이 코사인 유사도 |
|------|-------------|-------------------|
| FCR (ICM 없음) | 0.508 | 0.476 |
| FCR + ICM | **0.960** | **0.956** |

소스 세포유형에서 학습한 z_tx를 타겟 세포유형에 직접 적용했을 때, ICM 없이는 낮은 전이 성능(0.508)을 보이지만, ICM 정규화 후에는 0.960으로 급상승한다.

**직관:** ICM이 z_tx를 "세포유형이 어느 것이든 동일하게 작동하는 교란 효과"로 만들면, K562에서 학습한 교란 효과를 RPE1에 그대로 가져갈 수 있다. 타겟 세포유형에서 새로 학습할 필요가 없다. 단, z_x(공변량)는 타겟 세포유형의 데이터로만 얻어야 한다.

**실제 데이터:** RQ1과 마찬가지로 다세포유형 데이터가 필요하여 미검증 상태다.

### 5.4 소거실험 (합성 데이터, run_05)

6가지 구성을 합성 데이터에서 체계적으로 비교했다:

| # | 구성 | RQ1 (불변성) | RQ2-cross | RQ2-within | RQ3 (전이) |
|---|------|-------------|-----------|------------|-----------|
| 1 | FCR baseline | 0.5045 | 0.1988 | 0.2457 | 0.5041 |
| 2 | FCR + ICM | 0.9548 | 0.2021 | 0.0202 | 0.9344 |
| 3 | FCR + linear head | 0.8015 | 0.4036 | 0.2481 | 0.8090 |
| 4 | FCR + ICM + linear | 0.9660 | 0.0632 | 0.0963 | 0.9619 |
| 5 | FCR + ICM + comp loss | 0.9518 | **0.7915** | 0.3050 | 0.9695 |
| 6 | Full model | **0.9918** | 0.7712 | **0.5881** | **0.9934** |

**핵심 해석:**

- **ICM은 RQ1/RQ3에 결정적이다:** baseline 0.50 → +ICM 0.95 (불변성), 0.50 → 0.93 (전이). ICM 없이는 z_tx에 세포유형 정보가 섞여 불변성/전이 불가
- **ICM만으로는 RQ2가 개선되지 않는다:** 오히려 RQ2-within이 0.25→0.02로 악화. ICM이 z_tx 분포를 제약하여 조합 구조가 더 깨지는 효과
- **Comp loss가 RQ2의 핵심이다:** RQ2-cross가 0.20→0.79로 급등 (Config 5). 이중 KO 데이터로 조합 일관성을 명시적으로 강제
- **ICM + linear head의 역설:** RQ1/RQ3은 우수하나 RQ2가 최악(0.06). ICM이 z_tx 분포를 제약한 상태에서 선형 헤드가 조합에 비효율적
- **전체 모델(Config 6)이 종합 최고:** RQ1=0.99, RQ3=0.99, RQ2-cross=0.77

### 5.5 인코더 비선형성 분석

z_tx_learned와 z_tx_ground_truth 사이의 선형 R2를 측정하여 인코더의 비선형성을 정량화했다. 값이 높을수록 인코더가 더 선형적으로 매핑한다는 뜻이다:

| 구성 | Linear R2 | 잔차 노름 | 판정 |
|------|-----------|-----------|------|
| FCR baseline | 0.6897 | 0.7210 | 고비선형 |
| FCR + ICM | 0.8691 | 0.2007 | 중비선형 |
| FCR + linear head | 0.7271 | 0.6549 | 고비선형 |
| FCR + ICM + linear | 0.8670 | 0.1968 | 중비선형 |
| FCR + ICM + comp loss | **0.9119** | 0.2239 | 중비선형 |
| Full model | 0.8971 | 0.2171 | 중비선형 |

**핵심 해석:**

- **ICM이 인코더를 더 선형적으로 만든다:** 0.69 → 0.87. ICM의 MMD 정렬이 z_tx 분포를 구조화하여 인코더의 자유도를 제한, 결과적으로 비선형성 감소
- **Comp loss가 추가로 선형성을 높인다:** 0.87 → 0.91. 조합 일관성 제약이 인코더를 더 규칙적인 매핑으로 유도
- **Linear head만으로는 큰 도움이 안 된다:** 0.69 → 0.73 (상류 MLP 층이 여전히 비선형적이므로 마지막 층만 선형화해도 효과 제한적)
- 최고 구성(0.91)도 완전히 선형은 아니다 — VAE 인코딩에 내재적 비선형성이 존재하며, 이것이 잠재공간 조합이 깨지는 근본 원인

## 6. 논의

### 6.1 핵심 발견 요약

1. **ICM은 불변성/전이에 확실히 유효하다** (RQ1, RQ3). MMD 정규화가 z_tx 교세포 정렬에 강력하며, 이는 z_tx가 교란의 인과적 효과를 포착하고 있음을 지지한다.

2. **조합성은 유전자 공간에서 평가해야 한다.** 잠재공간 R2=0.05 vs 유전자공간 R2=0.88. 디코더가 인코더의 비선형성을 보상한다. 이는 VAE 기반 조합 예측 연구에서 반드시 고려해야 할 방법론적 교훈이다.

3. **실제 데이터에서는 comp loss가 불필요하다.** Norman 소거실험에서 baseline FCR이 이미 R2=0.88에 도달한다. Comp loss는 과도한 제약으로 오히려 성능을 저하시킨다(0.88→0.86). 합성에서 효과적이었던 이유는 지면 진실 z_tx가 있어 명시적 제약이 의미 있었기 때문이다.

4. **ICM이 인코더를 더 선형적으로 만든다** (linear R2 0.69→0.87). 이는 조합 구조 보존에 간접적으로 기여하지만, comp loss만큼 강력하지는 않다.

5. **가법성이 우위다.** 128개 이중 KO 중 110쌍(86%)에서 가법 조합이 승법보다 우수하다. 이는 독립 생물학적 경로의 교란이 발현 공간에서 가법적으로 결합한다는 가설과 부합한다.

6. **합성-실제 갭의 본질:** 합성 데이터에서 comp loss가 결정적이지만 실제에서는 불필요하다. 합성에서는 지면 진실 z_tx가 존재하여 잠재공간 조합 규칙을 강제할 수 있지만, 실제에서는 그런 지면 진실이 없고 인코더-디코더가 공동으로 조합 표현을 자연스럽게 학습한다.

### 6.2 RQ1/RQ3 실제 검증: 왜 아직 안 됐는가?

Norman 2019는 단일 세포유형(K562)만 포함하므로 교세포 불변성/전이를 검증할 수 없다. Replogle 2022는 K562와 RPE1 두 세포유형을 포함하나, RPE1 데이터 로딩에 실패했다. 다세포유형 Perturb-seq 데이터의 희소성이 병목이다.

현재 탐색 중인 대안 (7.2절 참조):
- **Replogle + Nadig/Replogle 2025:** K562, RPE1, Jurkat, HepG2 4개 세포주에서 2,053개 공유 필수유전자 CRISPRi 교란
- **sci-Plex3:** A549, K562, MCF7 3개 세포주에서 188개 약물 교란 (CRISPR가 아닌 약물이지만 검증 가능)

### 6.3 조합성의 유전자공간 평가가 갖는 의미

본 연구의 가장 중요한 방법론적 기여 중 하나는 "조합성은 유전자 공간에서 평가해야 한다"는 발견이다. 이는 기존 연구들이 잠재공간의 조합 구조를 직접 평가하던 관행에 도전한다.

**왜 중요한가?** 잠재공간에서 조합이 깨졌다고 해서 모델이 조합성을 학습하지 못한 것으로 결론 내리면, 실제로는 잘 작동하는 모델을 잘못 기각하게 된다. 평가 공간의 선택이 모델 선택에 영향을 미친다.

**일반화 가능성:** 이 발견은 VAE 기반 조합 예측 전반에 적용 가능하다. CPA, SAMS-VAE 등 다른 오토인코더 기반 방법에서도 동일한 현상이 발생할 가능성이 높다.

## 8. 부록

### A. 용어 사전

| 약어 | 전체 이름 | 정의 |
|------|----------|------|
| CRISPR | Clustered Regularly Interspaced Short Palindromic Repeats | 유전자 가위. 특정 유전자를 정밀하게 파괴(KO)하거나 억제(CRISPRi)하는 기술 |
| CRISPRi | CRISPR interference | 유전자를 파괴하지 않고 전사만 억제하는 CRISPR 변형 (dCas9-KRAB 사용) |
| FCR | Factorized Causal Representations | 관측 데이터를 인과적 잠재변수(z_x, z_t, z_tx)로 분해하는 표현 학습 방법 |
| ICM | Independent Causal Mechanisms | 인과 메커니즘은 맥락에 독립적이라는 원리 |
| IEM | Interchangeable Ensembles of Mechanisms | ICM의 수학적 형식화 (Schölkopf group, ICLR 2025) |
| KO | Knockout | 유전자를 제거하여 기능을 상실시키는 실험 |
| MMD | Maximum Mean Discrepancy | 두 확률 분포의 차이를 커널 공간에서 측정하는 비모수적 방법 |
| R2 | R-squared (결정계수) | 예측 모델이 실제 데이터의 분산을 얼마나 설명하는지. 1=완벽, 0=평균 수준 |
| scRNA-seq | Single-cell RNA sequencing | 개별 세포의 유전자 발현을 측정하는 시퀀싱 기술 |
| VAE | Variational Autoencoder | 잠재변수 모델. 인코더-디코더 구조로 데이터의 생성 요인을 학습 |
| z_x | Covariate latent | 세포 특이 공변량 (세포유형, 세포주기 등) |
| z_t | Treatment latent | 교란 식별자 (어떤 유전자가 KO되었는지) |
| z_tx | Interaction effect latent | 교란-세포 상호작용 효과 (교란이 이 세포에 미치는 실제 효과) |

### B. 주요 수식 요약

**VAE 손실:** 재구성 오차(예측이 실제와 얼마나 다른가) + 정규화 항(잠재변수가 표준정규분포를 따르도록 유도). 두 항의 균형이 학습 품질을 결정한다.

**MMD 정규화 항:** L_ICM = MMD(z_tx from cell type A, z_tx from cell type B). 두 세포유형의 z_tx 분포가 같아지도록 학습. 구체적으로는 각 그룹 내 쌍의 커널 값 평균 + 다른 그룹 간 쌍의 커널 값 평균의 차이를 최소화.

**조합 예측:** 가법은 z_tx_A + z_tx_B, 승법은 z_tx_A ⊙ z_tx_B (요소별 곱). 조합 결과를 디코더에 통과시켜 유전자 발현 예측값을 얻음.

**R2 (결정계수):** R2 = 1 - (예측 오차 제곱합) / (실제값-평균 오차 제곱합). 모델이 단순 평균보다 얼마나 나은지를 측정.

### C. 실험 이력표

| Run | 날짜 | 내용 | 주요 결과 |
