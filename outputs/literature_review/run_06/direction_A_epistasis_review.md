# Run 06: Direction A (에피스타시스 탐지) 심층 문헌 리뷰

**Date:** 2026-04-28 | **Stage:** Literature Review (loopback from Analysis)

## 1. 연구 배경

Perturb-seq 조합 섭동 예측에서 가법적 모델이 실패하는 경우, 그 잔차(residual) 자체가 에피스타시스 신호라는 가설. FCR-ICM의 조합 예측 잔차를 체계적으로 분석하여 유전자 상호작용을 탐지하는 것이 핵심 아이디어.

**핵심 질문:** 예측 잔차를 에피스타시스 vs 오차로 분해하는 원칙적 방법을 제안할 수 있는가?

## 2. SOTA

### 2.1 섭동 예측에서의 유전자 상호작용 처리

| 방법 | 접근 | GI 탐지 방식 | 잔차 활용 | 핵심 수치 |
|------|------|-------------|----------|----------|
| **GEARS** (Roohani et al., 2023, Nature Biotech) | GNN + 지식그래프 | 학습 데이터에서 직접 5개 GI subtype 분류 | **없음** — 잔차를 에피스타시스로 해석하지 않음 | 기존 대비 40% higher precision for GI subtypes; Norman 5,151 조합 예측; R2=0.64-0.93 (cell fitness) |
| **CPA** (Lotfollahi et al., 2023, Mol Syst Biol) | 가법적 임베딩 + 비선형 디코더 | 조합 예측 실패를 "오차"로 처리 | **없음** — 잔차를 신호로 해석하지 않음 | Norman OOD R2 저하; 5,329 missing 조합 imputation; baseline과 동등 성능인 경우 존재 |
| **PertSpectra** (Chang et al., 2026, PSB) | 행렬 분해 | 모듈 분해로 기능적 영향 예측 | **없음** | 조합 섭동의 해석 가능한 분해 |
| **scPGI-finder** (Chen et al., 2026, npj Precision Oncology) | 발현 상관관계 기반 | 고발현 유전자 쌍의 증식 연관성 | **없음** — 섭동 예측 잔차 아님 | 49,808 epithelial scPGIs; AUROC 0.974 |

### 2.2 잔차 기반 에피스타시스 탐지 (최근접 유사체)

| 방법 | 접근 | 잔차 활용 | 핵심 수치 | 비고 |
|------|------|----------|----------|------|
| **Pacalin et al.** (2024/2025, Nature Biotech, PMID:38760566) | CRISPRai 이중 섭동; 가법 모델 잔차로 GI 분류 | **YES** — 단일 섭동 log2FC 가법 합에서의 잔차 | SPI1-GATA1 시너지/완충 모드 식별; p<0.05 | **최근접 유사체** — 단 가법 합 사용(훈련된 예측기 아님) |
| **Otwinowski et al.** (2018, PNAS) | 단백질 DMS; I-spline 비선형 매핑 + HOC 잔차 | **PARTIALLY** — 잠재 형질 가법 모델 잔차 | 교차검증 r²~0.93 (GB1); sigma_HOC=0.7(GB1)/0.073(GFP) | 단백질 도메인; 섭동 예측과 무관 |
| **Birgy et al.** (2026, Nature Comms, PMID:41844643) | 단백질 안정성 모델 잔차 | **YES** — 안정성 모델 편차 = 구조적 에피스타시스 | 14,000+ 이중 돌연변이; 3D 상호작용 잔차와 일치 | 단백질 진화 도메인 |

**핵심 구분:** Pacalin et al.은 잔차를 에피스타시스로 해석하나, baseline이 **단순 가법 합**(훈련된 예측기 아님). 훈련된 신경망 예측기의 잔차를 체계적으로 에피스타시스 신호로 분해한 논문은 여전히 **0개**.

## 3. 베이스라인

### 3.1 Trivial Baseline: "가법 잔차 = 에피스타시스"

- 가법적 조합 예측과 실제의 차이를 단순히 에피스타시스로 간주
- **Recall ≈ 100%** (진짜 에피스타시스는 모두 포함)
- **Precision 낮음** — 잔차 = (a) 진짜 에피스타시스 + (b) 모델 오지정 + (c) 노이즈 + (d) 분포 이동

### 3.2 GEARS의 GI 탐지 방식 (가장 강력한 기존 베이스라인)

- 학습 데이터에서 5개 GI subtype 분류 (synergy/suppression/neomorphism/epistasis/redundancy)
- 기존 대비 40% higher precision
- **한계:** (1) 학습 데이터에 조합 섭동 필수 — 제로샷 불가, (2) 이산적 분류 — 연속적 에피스타시스 강도 측정 불가, (3) 잔차 분해 없음

### 3.3 CPA의 OOD 불확실성 프록시

- 임베딩 공간에서 관측 다양체까지의 거리를 불확실성 프록시로 사용
- Norman 데이터에서 baseline과 동등한 경우 존재
- **한계:** 보정되지 않음, 유전자별 불가, 에피스타시스 특이적 아님

## 4. 개념적 등가성 감사

### 핵심 아이디어: "예측 잔차에서 에피스타시스 탐지"

다른 용어로 재표현:
1. **인과추론 용어:** "가법적 인과 모델의 위반에서 비가법적 메커니즘 추론" → IEM, FCR 문헌에서 부분적 탐색 (ICM 위반 = 문맥 의존성), 잔차→에피스타시스 분해는 없음
2. **표현학습 용어:** "조합 표현의 분해 오차에서 상호작용 항 추출" → CPA, SAMS-VAE가 가법 분해 사용하나 잔차를 상호작용으로 해석하지 않음
3. **응용 용어:** "섭동 예측 실패에서 유전자 상호작용 신호 추출" → GEARS가 학습 데이터에서 GI 분류하나 **예측 잔차에서 추출하지 않음**
4. **통계적 용어:** "가법 모델의 잔차 분석으로 교호작용항 검출" → 회귀 분석에서 표준적 접근이나, **섭동 예측 컨텍스트에서 적용된 적 없음**
5. **생물학 용어:** "비가법적 효과의 체계적 탐지" → Norman 2019, PORTAL 2026이 경험적으로 탐지하나 원칙적 분해 방법 없음

### 결론: 직접 경쟁자 0개, 최근접 유사체 1개 확인

어떤 용어 체계로 검색해도 **"훈련된 예측 모델의 잔차를 체계적으로 에피스타시스 신호로 분해하는 원칙적 방법"** 을 제안한 논문을 발견하지 못함. **최근접 유사체**: Pacalin et al. (2025, Nature Biotech) — 단순 가법 합의 잔차로 GI 분류하나 훈련된 예측기 아님. 단백질 DMS 도메인에서는 Otwinowski(2018)와 Birgy(2026)가 유사 접근 사용하나 섭동 예측과 무관.

## 5. Gap (Framing으로 전달)

### 5.1 예측 잔차→에피스타시스 분해의 공백

GEARS는 학습 데이터에서 GI를 분류하나 **예측 잔차에서 추출하지 않음**. CPA는 조합 예측 실패를 오차로 처리. scPGI-finder는 발현 상관관계를 사용. **누구도 잔차를 신호로 해석하지 않음.**

### 5.2 에피스타시스 정의의 민감도

Valenzuela(2025)와 Ajmal(2025)이 독립적으로 보여준 바: **공식 선택(additive/multiplicative/product)에 따라 GI 점수와 상호작용 부호가 극적으로 변함.** Chitra et al. (2025, Nature Communications)도 chimeric vs multiplicative 공식이 정성적으로 다른 결과를 낳음을 입증. 이는 "잔차=에피스타시스" trivial baseline의 precision이 낮은 이유이자, **원칙적 잔차 분해의 필요성**을 강화.

### 5.3 대규모 검증 데이터의 등장

PORTAL(2026)의 665,856 쌍별 섭동 데이터가 **검증 기회**를 제공. 잔차 분해 방법의 정밀도/재현율을 대규모로 평가 가능.

### 5.4 FCR-ICM의 구조적 이점

FCR 분해(z_x/z_t/z_tx)는 잔차의 원천을 구분하는 구조적 이점 제공:
- z_tx 상호작용 항 = 이미 비가법 효과의 학습된 표현
- ICM 위반 = 문맥 의존적 효과 = 잠재적 에피스타시스
- 이 구조 없이는 잔차 = 에피스타시스 + 오차 + 노이즈를 분해할 방법이 없음

## 7. 다음 단계 (Framing으로 전달)

1. **잔차 분해 방법론 설계**: ICM 위반 점수 + MC Dropout 분산 + 가법 잔차를 결합하여 에피스타시스 확률 추정
2. **에피스타시스 공식 민감도 대응**: Valenzuela(2025)의 Product neutrality를 기준 공식으로 채택, 공식 선택에 따른 결과 변동을 명시적 불확실성으로 처리
3. **PORTAL 2026 검증 설계**: 665,856 쌍별 섭동을 holdout으로 사용하여 잔차 분해의 precision/recall 평가
4. **GEARS와의 차별화**: GEARS는 학습 데이터 필수 + 이산 분류 → 우리는 제로샷 잔차 분석 + 연속적 에피스타시스 강도
