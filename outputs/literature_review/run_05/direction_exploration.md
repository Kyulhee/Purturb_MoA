## A. 상위성(Epistasis) 탐지 — 예측 잔차에서 에피스타시스 체계적 탐지

### 핵심 아이디어
가법적 조합 예측이 실패할 때, 그 잔차(residual) 자체가 에피스타시스 신호. FCR-ICM의 조합 예측 잔차를 체계적으로 분석하여 유전자 상호작용을 탐지.

### 문헌 현황
- **직접 경쟁자: 0** — 예측 잔차를 에피스타시스 신호로 체계적으로 분석한 논문 없음
- GEARS: 유전자 상호작용을 학습 데이터에서 예측 (잔차에서 추출 아님)
- scPGI-finder: 발현 상관관계로 상호작용 탐지 (섭동 예측 잔차 아님)
- CPA: 조합 예측 실패를 "오차"로 처리 (신호로 해석하지 않음)
- Norman 2019: 추천시스템으로 상호작용 예측 (불확실성/AL 없음)

### Trivial Baseline
- "가법 잔차 = 에피스타시스" → recall ≈100% but precision 낮음
- 잔차 = (a) 진짜 에피스타시스 + (b) 모델 오지정 + (c) 노이즈 + (d) 분포 이동
- Chitra et al. (2024, bioRxiv): 가법/승법/키메라 공식 선택에 따라 10-60% 상호작용 부호가 바뀜
- **연구 기여**: 잔차를 에피스타시스 vs 오차로 분해하는 원칙적 방법 필요

### FCR-ICM 연결
- FCR-ICM 이미 Norman R2=0.88 → 12% 미설명 분산이 에피스타시스-풍부 잔차
- z_x/z_t/z_tx 분해: z_tx 상호작용 항이 이미 비가법 효과의 학습된 표현
- ICM 위반 = 문맥 의존적 효과 = 잠재적 에피스타시스

### PORTAL 2026 (Tang & Norman)
- **665,856 쌍별 섭동, 46M 클론** — 가장 큰 완전 유전자 상호작용 지도
- 이 데이터로 대규모 검증 가능

### 위험
- 잔차 분해의 통계적 방법론이 핵심 — 단순 "잔차=에피스타시스"는 publishable하지 않음
- 에피스타시스 공식 민감도(Chitra 2024) 주의 필요

## B. 불확실성 정량화 — 섭동 예측의 신뢰도 추정

### 핵심 아이디어
현재 섭동 예측 모델은 점 추정만 제공. 예측이 실패할 때(에피스타시스, 미경험 세포유형) 신호 없음. ICM 정규화가 자연스럽게 불확실성 신호를 제공.

### 문헌 현황
- **직접 경쟁자: 1-2** (CIPHER, Keeping SCORE — Goyal lab, 물리기반 접근)
- **보정된 구간이 있는 섭동 UQ: 0**
- **섭동 예측에 적용된 conformal prediction: 0**
- **유전자별 불확실성: 0**
- Goyal lab만이 섭동 UQ를 명시적으로 타겟 (물리기반, 딥러닝 아님)
- scRNA-seq 주해용 UQ: 3개 (Lopez-De-Castro, Theunissen, DEGU) — 다른 문제

### Trivial Baseline
- 앙상블/MC Dropout: 미보정, 유전자별 아님, 해석 불가
- Theunissen (2025): MC Dropout + Deep Ensembles이 scRNA-seq OOD 탐지에 작동 확인
- 예상 성능: 불확실성-오차 상관 Spearman rho ~0.3-0.5, 보정 불량

### FCR-ICM 연결 (매우 강력)
| 불확실성 유형 | 신호원 | 탐지 대상 |
|-------------|--------|----------|
| 인식적(모델) | MC Dropout 분산(디코더) | 학습 부족 유전자 |
| 우발적(데이터) | VAE 재구성 분산 | 생물학적 노이즈 큰 유전자 |
| ICM 위반 | z_tx MMD(교세포) | 세포유형 특이적 섭동 효과 |
| 조합적 | 가법 잔차 크기 | 에피스타시스 상호작용 |
| OOD | z_tx 훈련분포 거리 | 미경험 섭동 유형 |

### 타이밍 유리
- Kendiukhov (2026): 섭동 예측이 다중검정 보정 후 유의하지 않음 → 신뢰성 문제 심각
- Csendes (2025): 벤치마크의 섭동 특이 분산이 낮음 → UQ 필수
- GARM (2025): 유전자별 예측 가능성 편차 큼 → 유전자별 UQ 필요

### 위험
- Conformal prediction의 교환성 가정이 섭동 데이터에 성립하지 않을 수 있음
- 보정 평가에 held-out 섭동의 ground truth 필요

## C. 디코더 보상 — 잠재공간-유전자공간 갭의 일반적 원리

### 핵심 아이디어
잠재공간 R2=0.05 vs 유전자공간 R2=0.88 (10배 갭). 디코더가 인코더의 비선형 왜곡을 보상. 이 현상이 일반적인지, 평가에 어떤 함의가 있는지 연구.

### 문헌 현황
- **직접 경쟁자: 0** — 잠재공간-관측공간 평가 갭을 연구한 논문 없음
- 관련: Posterior collapse (46+ 논문) — "디코더가 잠재변수 무시" (역방향 현상)
- 관련: "Fixing a Broken ELBO" (Alemi 2017) — ELBO가 rate와 distortion 혼재
- 관련: "Generative Skip Models" (Dieng 2018) — 강력한 디코더가 잠재변소 무시 가능
- 핵심 차이: Posterior collapse은 "잠재 무용 + 출력 저하". 디코더 보상은 "잠재 저하 + 출력 양호". 다른 현상.

### Trivial Baseline
- "잠재공간과 유전자공간 지표를 모두 보고하라" — 관찰/권고사항, 방법 아님
- 보고서나 position paper 수준

### 위험
- **MEDIUM-HIGH for top venue**: 관찰적 기여, 신규 방법 아님
- NeurIPS/ICML은 방법론적 기여 강하게 선호
- 단일 아키텍처(FCR VAE)에서의 사례 → 일반성 입증 필요
- "그냥 posterior collapse 아님?" 오해 가능성

### 발표 가능성 향상 전략
1. 5개 이상 아키텍처(CPA, scGen, SAMS-VAE, GEARS, FCR)에서 현상 재현
2. "보상 지수" (Compensation Index = gene_R2 / latent_R2) 제안
3. 디코더 보상이 높은 모델이 특정 downstream task(교세포 전이 등)에서 실패하는지 입증
4. 이론적 분석: 어떤 조건에서 디코더 보상 발생하는지 (디코더 용량, 인코더 비선형성, 차원비)

## D. 능동학습/실험설계 — 어떤 조합 섭동을 다음에 실험할지 결정

### 핵심 아이디어
O(n²) 가능한 이중 섭동 중 제한된 실험 예산으로 어떤 조합을 테스트할지. FCR-ICM의 불확실성으로 실험 설계 안내.

### 문헌 현황
- **직접 경쟁자: 0** — Perturb-seq 조합 선택에 AL 적용한 논문 없음
- 근접: Bayesian AL for GRN 구조 학습 (2025, BMC Bioinformatics)
- 근접: BO-EVO 단백질 공학 (2023) — 생물학적 조합 탐색에서 4.8배 개선
- 근접: 반복적 DL 설계 (2025, Cell Systems) — 생물학에서 AL 루프 입증
- 2026 리뷰(PMID 41715150): "반복적, 정보 효율적 스크리닝"을 차세대 방향으로 명시 → 1-2년 윈도우

### Trivial Baseline
- 랜덤 선택: Norman 2019에서 8,515 가능 조합 중 104개만 실험 (1.2%)
- 독립 경로의 대부분은 가법적 → 정보 이득 낮음
- BO-EVO 선례: 공간의 1% 탐색으로 4.8배 개선
- 예상: 정보 기반 선택이 랜덤 대비 5-10배 효율적

### FCR-ICM 연결
- z_tx 불확실성 + ICM 위반 = 자연스러운 획득 함수
- Norman 2019 holdout으로 AL 시뮬레이션 가능 (104 double-KO 보류)

### 위험
- 독립 기여보다 FCR-ICM의 평가 프레임워크/응용 사례로 더 적합
- 단독 논문보다 본 논문의 섹션으로 강력

## 종합 판단 및 제안

### 최우선 방향: A+B 결합 (상위성 탐지 + 불확실성 정량화)

**결합 논리:**
1. A와 B는 자연스럽게 연결 — 조합 예측 잔차의 불확실성 정량화 → 잔차에서 에피스타시스 분리
2. 두 방향 모두 직접 경쟁자 0개 (A) 또는 1-2개 (B)
3. FCR-ICM의 구조(z_x/z_t/z_tx 분해, ICM 정규화)가 두 문제 모두에 자연스럽게 활용
4. Mean Shift(R2=0.82)의 약점(불확실성 없음, 비가법적 효과 포착 불가)을 정확히 공격

**연구 질문 (초안):**
"인과 분해된 섭동 표현(z_tx)의 조합 예측 불확실성을 정량화할 때, (1) 어떤 조합 섭동이 비가법적(에피스타시스) 상호작용을 가질지 예측할 수 있는가? (2) 이 불확실성이 제한된 실험 예산 하에서 어떤 조합을 우선 실험해야 할지 안내할 수 있는가?"

**경쟁 밀도 평가:**
- "에피스타시스 탐지 from 잔차": 0개
- "섭동 예측 불확실성 정량화": 1-2개 (CIPHER만, 물리기반)
- "조합 섭동 능동학습": 0개
- **총 직접 경쟁자: 1개** → docs/02 기준 통과 (< 3)

**기여 분해 테스트:**
| 성분 | 독립적 신규성 | 기존 작업 |
|------|-------------|----------|
| VAE 분해 | 낮음 | BuDDI, CPA가 이미 함 |
| 조합 예측 | 낮음 | GEARS, CPA가 이미 함 |
| 불확실성 정량화 (섭동) | **높음** | CIPHER만 (물리기반, 딥러닝 아님) |
| 잔차→에피스타시스 분해 | **매우 높음** | 0개 |
| ICM 기반 불확실성 해석 | **높음** | 0개 (ICM 위반 = 문맥 의존성 신호) |
| 능동학습 (Perturb-seq) | **높음** | 0개 |

→ 4/6 성분이 독립적으로 신규 → 기여 분해 테스트 통과

**실패 모드 분류:**
| 실패 모드 | 징후 있음? | 근거 |
|-----------|-----------|------|
| 포화 시장 | 아니오 | 직접 경쟁자 1개 |
| 사소한 개선 | 확인 필요 | Mean Shift R2=0.82 vs 우리 R2=0.92 (+0.10) — but 불확실성/에피스타시스는 Mean Shift가 아예 불가 |
| 재포장 | 아니오 | ICM 정규화 ≠ 도메인 적응 (본 연구에서 입증) |
| 평가 함정 | 확인 필요 | 잠재공간 vs 유전자공간 갭 존재 |
| 데이터 의존 | 아니오 | Norman 2019 + Replogle 2022 모두 공개 |

→ 0-1개 실패 모드 징후 → docs/02 기준 통과 (< 2)
