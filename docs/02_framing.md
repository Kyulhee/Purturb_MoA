## 신규성 세이프가드 (Novelty Safeguards)

### 1. 신규성 사전 검사 (Novelty Pre-check)
연구 질문을 확정하기 전에, 제안하는 핵심 기여가 **이미 다른 용어로 발표되었는지** 확인. 문헌 리뷰에서 누락된 경쟁 방법이 없는지 최종 점검.

**Why:** run_08에서 FCR+ICM의 교세포 전이가 "새로운" 것으로 가정했으나, BuDDI(VAE 분해+도메인 불변성), C3TL(인과 불변성+교세포 전이), scDRP(β-VAE 분해+인과성)가 이미 동일/유사 접근을 수행했음이 드러남. Framing 단계에서 이 점검을 수행했으면 8 runs 전에 방향을 조정했을 것.

**How to apply:** 연구 질문 확정 전, 핵심 기여를 2-3개의 다른 용어 체계로 검색. 직접 경쟁자가 발견되면 기여 범위를 수정하거나 차별화 포인트를 명확히.

### 2. 경쟁 밀도 평가 (Competitive Density Check)
핵심 아이디어를 2-3개의 다른 용어로 검색하여 **직접 경쟁자 수를 정량화**. 3개 이상의 직접 경쟁자가 있으면 방향 재고.

**Why:** FCR-ICM 케이스에서 C3TL + BuDDI + scDRP + XTransferCDR + CPA = 5개의 직접 경쟁자가 존재했음. 이를 초기에 알았으면 방향을 달리했을 것.

**How to apply:** 각 용어 체계에서 발견된 직접 경쟁자 수를 기록. 총 3개 이상이면 (a) 차별화 포인트 재검토, (b) 문제 재정의, (c) 방향 전환 중 하나를 선택.

### 3. 기여 분해 테스트 (Contribution Decomposition Test)
제안하는 기여를 개별 성분으로 분해하고 각 성분이 **독립적으로 신규한지** 평가. 개별 성분이 모두 기존에 존재하면 조합의 신규성만 남는데, 조합 신규성은 약한 형태.

**Why:** "ICM이 전이를 가능하게 한다"의 성분 분해: (1) VAE 분해 → BuDDI/CPA가 이미 함, (2) MMD 정규화 → 도메인 적응에서 표준, (3) 교세포 전이 적용 → C3TL/scGen이 이미 함. 개별 성분이 모두 기존에 존재하여 조합 신규성만 남았고, 그마저도 약함.

**How to apply:** 각 기여 성분을 나열하고, 각각에 대해 "이 성분을 단독으로 제안한 논문이 있는가?"를 검색. 모든 성분이 기존에 존재하면 방향 재고.

### 4. 실패 모드 분류 (Failure Mode Classification)
연구 방향이 실패할 수 있는 시나리오를 미리 분류하고, 각 시나리오의 징후를 정의.

| 실패 모드 | 정의 | 징후 | 사례 |
|-----------|------|------|------|
| **포화 시장** | 동일/유사 접근이 이미 3개 이상 | 경쟁 밀도 ≥ 3 | FCR-ICM 교세포 전이 (5개 경쟁자) |
| **사소한 개선** | Trivial baseline 대비 개선이 미미 | ΔR2 < 0.10 또는 Δcorr < 0.05 | Mean Shift R2=0.82 vs FCR+ICM R2=0.92 |
| **재포장** | 기존 방법을 다른 용어로 재진술 | 개념적 등가성 감사에서 겹침 | ICM 정규화 = 도메인 적응 |
| **평가 함정** | 좋은 지표에서만 성공, 중요 지표에서 실패 | 평가 지표 선택에 따라 결과 반전 | 잠재공간 R2=0.05 vs 유전자공간 R2=0.88 |
| **데이터 의존** | 특정 데이터셋에서만 작동 | 교차 검증 시 성능 급락 | — |

**How to apply:** Framing 단계에서 각 실패 모드에 대해 자문. 2개 이상의 실패 모드에서 "징후 있음"이면 방향 재고.

## Key Questions
- 이 질문은 어떤 기존 한계(gap)에서 비롯되었는가?
- 우리가 풀고자 하는 문제는 정확히 무엇인가?
- 성공의 기준은 무엇인가? (정량적)
- 어떤 데이터로, 어떤 지표로 측정하는가?
- 베이스라인 대비 얼마나 개선해야 의미 있는가?
- **이 기여의 개별 성분이 각각 이미 존재하는가?** (기여 분해 테스트)
- **동일 아이디어가 다른 용어로 이미 발표되었는가?** (경쟁 밀도 평가)
- **Trivial baseline 대비 개선이 의미 있는가?** (사소한 기준선 하한)
